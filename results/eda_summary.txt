============================================================

STEP 1: Outcome

  - Skewness: cd80 1.73, preanti 1.19, cd40 0.76, wtkg 0.71, age 0.64. Sirf cd80 aur preanti ki skew 1 se zyada.
  - preanti: 41% mareez 0 par (zero ka dher).

STEP 3: Bekaar / duplicate features
  - zprior: sab 2139 mareezon ki ek hi value (constant). oprior: 97.8% mareezon par 0 (lagbhag constant).
  - strat se str2 poori tarah tay hota hai: haan. arms se treat poori tarah tay hota hai: haan.

STEP 4: Baseline balance
  - Sab se bara SMD 0.071 (wtkg). Koi feature 0.1 se upar nahi: arms shuru mein barabar.

STEP 5: Censoring by arm
  - Event ka hissa: ZDV 34.0%, ZDV+ddI 19.7%, ZDV+zal 20.8%, ddI 22.8% (chi-square p = 3.9e-08).
  - Censored mareezon ka median follow-up: ZDV 1033, ZDV+ddI 1063, ZDV+zal 1054, ddI 1052 din (sab arms mein qareeb, dropout ka bias nazar nahi aata).

STEP 6: Features ka aapas ka rishta
  - Sab se mazboot Spearman jore: strat-preanti 0.96, strat-z30 0.85, z30-preanti 0.83, gender-homo 0.61.
  - Cramer's V ke sab se mazboot jore: strat-z30 0.90, gender-homo 0.61, homo-hemo 0.39.
  - arms ka kisi bhi feature se sab se bara V 0.011 (randomization theek).

STEP 7: Kaplan-Meier
  - 900 din par event se bache hue: ZDV 65.0%, ZDV+ddI 81.9%, ZDV+zal 81.7%, ddI 79.8%. Log-rank p: 4 arms 1.2e-10, ZDV vs baqi 5e-12.

  - cd80: log-rank p = 0.018; event rate pehle group mein 21.5%, aakhri group mein 29.5%
  - preanti: log-rank p = 1.1e-06; event rate pehle group mein 18.0%, aakhri group mein 32.4%
  - karnof: log-rank p = 2.3e-06; event rate pehle group mein 38.2%, aakhri group mein 21.1%
  - age: log-rank p = 0.15; event rate pehle group mein 22.2%, aakhri group mein 28.7%
  - wtkg: log-rank p = 0.59; event rate pehle group mein 23.2%, aakhri group mein 26.1%

STEP 8: Binary features ka event rate (feature = 1 minus feature = 0, point mein)

STEP 9: Treatment ka asar subgroups mein
  - Sab mareez: HR 0.53 (0.45 - 0.64). Subgroups mein HR 0.46 se 0.70, sab 1 se neeche (doosre treatments ki taraf).
  - Jahan 95% daira 1 ko chhuta hai: symptom = 1 (n=370, HR 0.70), gender = 0 (n=368, HR 0.66), drugs = 1 (n=281, HR 0.57). Yeh chhote groups hain jahan events kam hain.
  - karnof = 100 mein HR 0.46 aur karnof < 100 mein 0.64: halka ishara, daire aapas mein milte hain.

STEP 10: Patterns
  - cd40 (deciles): event rate 45.4% se girta hai 14.1% tak. cd80: 19.2% se 29.9% tak.
  - preanti: event rate 18.0% (0 din) se 32.4% (730+ din) tak barhta hai.
  - age aur wtkg ke deciles mein sirf halka utar chadhao (shor jaisa).
  - cd40 aur cd80 ka Spearman rishta 0.23 (halka).

PEHLE KE CHECKS (cleaning, linearity, outliers)
